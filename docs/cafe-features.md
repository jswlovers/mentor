# 미용카페 구현 현황

2026-10-14 기준. 미용커플과 네이버 ‘헤어쟁이들의 좋은만남’의 공개 메뉴·대표 게시판에서 확인한 기능을 미용 SOS 내부 서비스로 구현했다. 이전 버전의 외부 커뮤니티 바로가기 영역은 내부 서비스 메뉴로 교체했다.

## 채용·구직 권한

- 정규 채용: 인증된 원장. 알바·스페어 채용: 인증된 원장·디자이너. 구직: 누구나.
- 인증: 매장(`/salon`)에 원장·디자이너로 소속되어 있거나 카페 등업 1 이상.
- 입력 항목: 채용은 매장명·모집 직급·급여(필수)와 근무 시간·모집 인원이다. 구직은 희망 직급·경력(필수)과 희망 급여·근무 시간이다.
- 구직 글의 본문, 사진, 첨부는 채용 권한이 있는 회원, 작성자, 관리자만 볼 수 있다. 구직 글에는 신청 기능이 없다. 채용 권한이 있는 회원만 비공개 문의로 채용을 제안할 수 있다. 맞춤 채용에는 채용 글만 나온다.
- 화면 이름은 ‘라운지’다(주소는 `/cafe` 유지). 질문하기 메뉴는 없앴고, 동료 질문은 ‘미용 질문·답변’ 게시판을 쓴다.
- 라운지 왼쪽 카테고리: 전체글 · 최근 본 글 · 저장한 글 · 내가 쓴 글(로그인) 아래에 큰 분류 5개. 분류 이름을 누르면 그 분류 전체 글(`group` 파라미터), 펼치면 세부 게시판.

## 내부 경로

- `/cafe`: 전체 게시판과 내부 서비스 메뉴
- `/cafe/write`, `/cafe/posts/:id`: 글쓰기·상세·신청·문의·첨부
- `/cafe/services/members`, `/profile`, `/recent`, `/resumes`, `/matches`: 회원·활동·이력서·추천
- `/cafe/services/activity`, `/inbox`: 신청 관리·문의함
- `/cafe/services/market`, `/cart`, `/orders`, `/selling`: 쇼핑·주문·판매
- `/cafe/services/admin`: 등업·노출 요금/심사·신고

`/profile` 등 위의 축약 경로는 모두 `/cafe/services/` 아래에 있다.

## 결제와 운영 방식

상품은 계좌 입금으로 주문을 처리한다. 시스템은 입금 자체를 실행하거나 은행에서 자동 확인하지 않는다. 판매자가 실제 입금·환불을 확인하고 상태를 처리한다. 카드 PG와 택배사 자동 조회는 연결되지 않았으며 송장 정보를 내부에 표시한다. 가격·배송비가 장바구니 확인 후 변경되면 주문을 거절해 다시 확인하도록 한다. 같은 판매자의 배송비는 상품 중 가장 큰 배송비로 한 번 부과한다.

추천 노출 심사비는 관리자가 설정하며 기본 0코인이다. 유료로 설정하면 신청 화면에 비용을 표시하고 동의한 회원만 코인을 사용한다. 반려 환불은 중복 처리되지 않는다. 맞춤 채용은 지역·분야의 일치도를 계산하며 외부 AI 모델을 호출하지 않는다.

외부 사이트의 게시글·상품·회원 DB를 복사하지 않는다. 미용 SOS 회원과 판매자가 실제 콘텐츠를 등록한다. 원본 서비스의 로그인 후 비공개 화면·운영 서버 내부 기능까지 동일하다는 의미는 아니다.

## 저장·권한·검증

기존 SQLite의 `cafe_*` 테이블과 `data/uploads/cafe`를 사용하며 기존 백업에 포함된다. 공개되지 않은 이력서, 문의, 배송지·계좌, 직급·등급 자료는 권한에 따라 노출한다. 게시글 삭제는 숨김 처리하고 해당 첨부 접근도 차단한다.

별도 `cafe-e2e-*` DB와 3004 포트에서 통합 검증:

- `scripts/e2e-cafe.mjs`: 기본 기능 63개 검사
- `scripts/e2e-cafe-services.mjs`: 확장 기능 90개 검사
- 총 153개 검사 통과. ESLint·TypeScript·프로덕션 빌드 통과.
- 브라우저에서 로그인→내부 판매 관리→상품 등록/저장, 신청 관리→교육 상세→첨부 자료·노출 신청·댓글 화면 연결 확인.

서버, 개발 서버, 프로덕션 서버는 3004 포트로 통일했다.

외부 이동 제거: 글쓰기의 참고 링크 입력과 상세 화면의 외부 링크 버튼을 제거했다. 기존 저장 링크는 표시하지 않으며, API에서도 신규 외부 링크 등록을 거절한다. 교육·영상·자료는 내부 첨부로 이용한다.
