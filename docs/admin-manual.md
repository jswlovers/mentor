# 미용 SOS 관리자 매뉴얼

운영자용 문서입니다. 화면 사용법(1~3장)과 서버 운영(4~8장)으로 나뉩니다.

- 서비스: https://mentor.sean2022.one:3004 (서버 PC: `D:\github\mentor`)
- 기술: Next.js 16 + SQLite(내장 `node:sqlite`), Node가 HTTPS를 직접 처리

---

## 1. 관리자 계정

### 만들기
관리자는 가입만으로 될 수 없습니다(보안). 순서:
1. 서비스에서 일반 회원으로 **가입**
2. 서버 PC에서 실행:
   ```
   cd D:\github\mentor
   npm run make-admin -- <아이디>
   ```
3. 로그인하면 상단 메뉴에 **관리자**가 나타납니다. (바로 반영됨, 재로그인 불필요)

### 현재 계정 (초기 세팅)
| 구분 | 아이디 | 비고 |
|---|---|---|
| 관리자 | `admin` | 비밀번호는 전달받은 것 사용. **내 정보에서 즉시 변경 권장** |
| 테스트 질문자 | `test_asker` / `test1234!` | 코인 30만 충전됨 |
| 테스트 전문가 | `test_expert` / `test1234!` | 승인 완료 |

> ⚠️ 테스트 계정은 알려진 비밀번호입니다. 운영 전 **회원 탭에서 정지**하거나 비밀번호를 초기화(임시 비밀번호는 전달하지 않고 버리기)하세요. 계정 삭제 기능은 없습니다.

### 가입 시 휴대폰 인증 · 직급
회원가입에는 휴대폰 인증(같은 번호로 중복가입 방지)과 직급(원장님/디자이너/인턴) 선택이 필요합니다. **아직 실제 SMS 업체 연동 전이라 인증번호를 문자로 보내지 않고 화면에 그대로 보여줍니다**(개발/테스트용). 실제 SMS를 연동하려면 `lib/server/phone.ts`의 `issueCode()`가 반환하는 인증번호를 문자로 보내도록 바꾸고, `app/api/auth/phone/send/route.ts`가 응답에 `devCode`를 담지 않도록 수정하세요(업체 API 키 발급 필요, 예: 알리고·NHN Toast·Twilio).

직급 게시판(같은 직급끼리만 보이는 게시판)과 구인구직(채용/구직 · 도시 · 지역) 게시판은 회원이 스스로 쓰는 공개 기능이라 관리자가 따로 승인할 일은 없습니다.

## 2. 관리자 화면 (`/admin`)

상단 탭: **충전 · 전문가 · 출금 · 문의 · 회원 · 원장 · 메시지**. 처리가 필요한 건(대기)이 각 목록 맨 위에 옵니다. 처리하면 해당 회원에게 알림이 자동 발송됩니다.

### 2-1. 충전 (무통장입금 승인)
1. 은행 앱에서 입금 내역 확인
2. 목록의 **회원 이름 · 금액 · 입금자명**과 실제 입금을 대조
3. 일치하면 **승인** → 회원에게 코인 지급 + 알림
4. 입금이 없거나 이상하면 **반려**(사유 입력) → 회원에게 사유 알림

- 이미 처리된 건은 다시 처리할 수 없습니다(이중 승인 방지).
- 입금 계좌 안내는 `.env.local`의 `BANK_INFO`로 설정합니다(6장). 설정 전에는 회원 화면의 무통장 신청 버튼이 비활성입니다.
- 카드 결제(토스)는 자동 승인되므로 이 목록에서 처리할 일이 없습니다.

### 2-2. 전문가 (승인)
- 신청자의 **소개(경력·자격·분야)**를 읽고 **승인/반려**합니다.
- 면허·경력을 별도로 확인해야 한다면 승인 전에 고객센터/연락처로 확인하세요(자격 증빙 업로드 기능은 아직 없음).
- 승인되면 그 회원은 상담 참여·수익 정산이 가능하고 답변에 **검증 전문가** 배지가 붙습니다.

### 2-3. 출금 (전문가 정산)
1. 목록에서 **전문가 · 금액 · 은행/계좌/예금주** 확인
2. 은행에서 **직접 이체**
3. 이체 후 **이체 완료** 클릭 (전문가에게 알림)
4. 이체할 수 없는 사유가 있으면 **반려**(사유 입력) → 금액이 전문가 수익으로 되돌아감

> 이체는 반드시 **은행에서 먼저** 하고 '이체 완료'를 누르세요. 시스템은 이체를 대신하지 않습니다.

### 2-4. 문의 (고객센터)
종류: 불만·클레임 / 환불 요청 / 회원 신고 / 기타

- **답변·완료**: 답변 내용을 입력하면 처리 완료 + 회원에게 알림
- **환불** (환불 요청 건만): 환불할 **코인 수**와 메모를 입력하면 회원 코인으로 즉시 환불 + 처리 완료
  - 환불 판단 기준 예시: 전문가가 참여했으나 응답이 없었음, 상담 시간 대비 명백한 서비스 미이행 등. 채팅 내용은 `data\mentor.sqlite`의 `messages` 테이블에 있어요(관리자 화면에서는 채팅을 열람할 수 없음).
- **회원 신고**: 대상과 사유를 확인. 같은 회원에 대한 신고가 **5건**이 되면 시스템이 **자동 정지**합니다. 허위·보복 신고가 의심되면 신고자를 확인하고, 잘못 정지된 회원은 회원 탭에서 **정지 해제**하세요.

### 2-5. 회원
- **정지 / 정지 해제**: 정지하면 즉시 로그아웃되고 로그인이 막힙니다. (관리자 계정은 정지 불가)
- **비밀번호 초기화**: 임시 비밀번호가 화면에 **한 번** 표시됩니다. 반드시 **본인 확인 후**(가입 정보·문의 내용 등) 회원에게 전달하고 변경하도록 안내하세요. 기존 로그인은 모두 끊깁니다.

### 2-6. 원장 (코인 장부)
모든 코인 이동이 **복식부기**(차변=대변)로 기록됩니다. 최근 200건이 표시됩니다.

| 계정 | 의미 |
|---|---|
| `user:<회원>` | 회원 코인 잔액 |
| `earn:<전문가>` | 전문가 수익(출금 가능) |
| `platform:cash` | 충전으로 들어온 현금 상당액 (충전·환불 시 움직임) |
| `platform:revenue` | 플랫폼 매출 (질문자 사용액 − 전문가 몫) |
| `platform:withdraw_hold` | 출금 신청 후 이체 전 보류액 |
| `platform:payout` | 지급 완료된 출금 누계 |

회원 잔액은 별도 저장값이 아니라 **이 원장에서 매번 계산**됩니다. (데모용 `platform:promo`는 가입 보너스를 켰을 때만 사용)

### 2-7-1. 자동 처리 (서버가 하는 일)
- **전문가 호출**: 질문자가 상담을 시작하면 그 질문의 분야를 담당하는(또는 분야를 정하지 않은) 응대 가능 전문가에게 알림을 보냅니다. 평점이 높고 최근 호출이 적은 순서이며, 질문자가 전문가를 지정했으면 그 전문가가 먼저입니다.
- **자동 환불**: 전문가가 제한 시간 내 참여하지 않은 상담은 자동으로 취소되고 질문자가 쓴 금액이 전액 환불됩니다(원장에 `refund`로 기록). 전문가가 참여한 상담은 대상이 아닙니다.
- 이 작업은 서버가 켜져 있는 동안 1분마다 실행됩니다. 서버가 꺼져 있던 시간만큼 지연될 수 있으나, 다시 켜지면 밀린 건을 이어서 처리합니다. 서버 로그에 `[sweeper] 시작: …` 이 보이면 정상입니다.

### 2-7. 메시지 (카카오 알림톡 · 문자)
회원의 카카오톡(알림톡)·문자 발송 현황과 **안내 메시지 발송**을 다룹니다.

- 위쪽에 **수신 가능 회원**(휴대폰 인증 + 수신 동의) / 인증 / 전체 수가 표시됩니다.
- **안내 발송**: 받는 사람에 회원 **아이디** 또는 `all`(수신 동의 회원 전체)을 넣고 내용(500자 이내)을 입력 → **발송**.
  - 서비스 점검·정책 변경·결제 안내 같은 **서비스 안내 전용**입니다. **광고·홍보 내용은 보내지 마세요**(별도 광고 수신 동의 필요, 정보통신망법).
  - 결과 창의 `건너뜀`은 휴대폰 미인증 또는 수신 미동의 회원입니다. `테스트(mock)`은 실제 발송이 아니라 기록만 한 것입니다.
- 아래 **발송 기록**(최근 200건)에 채널(kakao/sms), 종류, 상태(sent 발송 / mock 테스트 / failed 실패), 문구가 남습니다.
- 회원에게는 이벤트(새 메시지, 전문가 참여, 충전 승인/반려, 전문가 승인/반려, 출금 지급, 문의 처리, 답변 등록) 때 **자동 발송**됩니다. 같은 종류(새 메시지·답변)는 30분에 한 번만 보냅니다.

#### 실제 발송 켜기 (한 번만 준비)
현재는 **mock 모드**(서버 로그에만 출력)입니다. 실제로 보내려면:
1. [카카오 비즈니스](https://business.kakao.com)에서 **카카오톡 채널** 개설·비즈니스 인증
2. [Solapi](https://solapi.com) 가입 → **카카오 채널 연동**(채널 ID `pfId` 확인) → **발신번호 등록** → 잔액 충전
3. Solapi에서 **API Key/Secret** 발급
4. 알림톡 **템플릿 등록·심사** — 아래 표의 문구를 **그대로**(변수는 `#{이름}`) 등록하고, 승인된 템플릿 ID를 확인
5. `.env.local`에 값 입력 후 **서버 재시작** (5장 표)

| 종류 (env 변수) | 템플릿 문구 (등록 시 그대로) | 변수 |
|---|---|---|
| 새 메시지 (`KAKAO_TEMPLATE_NEW_MESSAGE`) | `#{sender}님이 상담 채팅에 새 메시지를 보냈어요.` | sender |
| 상담 호출 → 전문가 (`..._CONSULT_REQUEST`) | `#{asker}님의 #{category} 질문에 1:1 상담이 열렸어요. 참여하면 수익이 쌓여요.` | asker, category |
| 자동 환불 (`..._CONSULT_EXPIRED`) | `전문가가 참여하지 않아 상담이 자동 취소되고 전액 환불됐어요.` | 없음 |
| 전문가 참여 (`..._EXPERT_JOINED`) | `#{expert} 전문가가 상담에 참여했어요.` | expert |
| 답변 등록 (`..._ANSWER_RECEIVED`) | `내 질문에 #{name}님이 답변했어요.` | name |
| 충전 승인 (`..._CHARGE_APPROVED`) | `#{coins}코인이 충전됐어요.` | coins |
| 충전 반려 (`..._CHARGE_REJECTED`) | `충전 신청이 반려됐어요. 사유: #{reason}` | reason |
| 전문가 승인 (`..._EXPERT_APPROVED`) | `전문가로 승인됐어요. 이제 상담에 참여할 수 있어요.` | 없음 |
| 전문가 반려 (`..._EXPERT_REJECTED`) | `전문가 신청이 반려됐어요. 내용을 보완해 다시 신청해주세요.` | 없음 |
| 출금 지급 (`..._WITHDRAW_PAID`) | `#{amount}원 출금이 지급됐어요.` | amount |
| 문의 처리 (`..._TICKET_RESOLVED`) | `문의가 처리됐어요. 앱에서 답변을 확인해주세요.` | 없음 |
| 관리자 안내 (`..._ADMIN_NOTICE`) | `#{message}` | message |

- 발송 문구 앞에는 자동으로 `[미용 SOS] `가 붙습니다. 심사받는 문구에도 같은 접두어를 포함하세요(예: `[미용 SOS] #{sender}님이 …`).
- 템플릿 ID가 **없는 종류**는 문자(SMS)로 보냅니다. 문자 발송도 실제로 켜려면 `SMS_PROVIDER=solapi`. 둘 다 없으면 mock입니다.
- 알림톡이 실패하면 Solapi가 문자로 **자동 대체 발송**합니다.
- `관리자 안내(#{message})`처럼 자유 문구 템플릿은 카카오 심사에서 반려될 수 있습니다. 반려되면 용도별 고정 문구 템플릿(점검 안내 등)으로 나누어 등록하세요.
- 발송 비용은 Solapi 요금표(알림톡·문자 건당)를 확인하세요.

## 3. 정책 요약 (운영자가 알아야 할 규칙)

| 항목 | 값 | 비고 |
|---|---|---|
| 코인 | 1코인 = 1원, 최소 충전 1,000원 | |
| 상담 시작비 | 50,000코인 | 질문 작성자만 신청 가능 |
| 쪽지 | 글자당 10코인, 최소 500, 1회 200자 이내, 첨부 +500 | |
| 통화 | 보이스톡 초당 10 / 페이스톡 초당 100 | 시작·참여 잔액 > 3,000, 통화 중 ≤ 1,500이면 강제 종료 |
| 과금 대상 | 상담을 신청한 **질문자만** | 전문가는 무료 |
| 전문가 몫 | 질문자 사용액의 **70%** | 플랫폼 수수료 30% |
| 전문가 참여 시 | 그때까지의 사용액을 한꺼번에 정산, 이후는 건별 즉시 정산 | |
| 최소 출금 | 10,000코인 | |
| 취소·환불 | 전문가 참여 **전**에는 질문자가 전액 환불 취소 가능 | 참여 후는 고객센터 환불 요청 |
| 신고 자동 정지 | 같은 회원 신고 5건 | |
| 무응답 자동 환불 | 상담 시작 후 **60분** 내 전문가 미참여 시 자동 취소·전액 환불 | 1분마다 서버가 확인 |
| 전문가 호출 | 상담이 열리면 분야 맞는 전문가 **5명**에게 알림 → 15분 뒤 다음 5명 | 1인당 시간당 3건, 카카오·문자는 23~08시 제외 |
| 질문 사진 | 최대 3장, 장당 5MB, **공개** | |

요금·비율·자동 환불 시간·호출 인원은 코드 한 곳에서 바꿉니다: **`lib/server/pricing.ts`** (`AUTO_REFUND_MINUTES`, `WAVE2_MINUTES`, `CALL_WAVE_SIZE`, `CALL_HOURLY_CAP`) (수정 후 재빌드·재시작 필요, 5장). 이미 처리된 거래에는 소급되지 않습니다.

## 4. 서버 운영

### 4-1. 시작 / 재시작 / 중지
서버 PC에서 (PowerShell):
```powershell
cd D:\github\mentor

# 코드나 설정을 바꿨다면 먼저 빌드
npm run build

# 실행 (포트 3004, HTTPS)
npm run serve
```
- `npm run serve`는 창을 열어 둔 상태로 실행됩니다. 백그라운드 실행 예:
  ```powershell
  Start-Process node -ArgumentList "--env-file=.env.local","server.mjs","--prod" -WorkingDirectory D:\github\mentor -WindowStyle Hidden -RedirectStandardOutput D:\github\mentor\data\server.log -RedirectStandardError D:\github\mentor\data\server.err
  ```
- 중지: 3004 포트를 쓰는 프로세스를 종료
  ```powershell
  Get-NetTCPConnection -LocalPort 3004 -State Listen | ForEach-Object { Stop-Process -Id $_.OwningProcess -Force }
  ```
- **PC를 재부팅하면 서버가 꺼집니다.** 자동 시작이 필요하면 Windows 작업 스케줄러에 "로그온 시 위 실행 명령"을 등록하세요.
- `.env.local`을 바꾼 경우에도 **재시작**해야 반영됩니다(빌드는 불필요).

### 4-2. 로그

## 5. 설정값 (`D:\github\mentor\.env.local`)

`.env.local`은 git에 올라가지 않으며 비밀 키가 들어 있으니 유출에 주의하세요. 예시는 `.env.example`.

| `KAKAO_TEMPLATE_*` | 종류별 알림톡 템플릿 ID (2-7장 표) | 해당 종류는 문자/mock |
| `SMS_PROVIDER` | `solapi`면 문자·인증번호 실발송 | mock (인증번호가 서버 로그에만 찍힘) |

## 6. 도메인 · 인증서 · 네트워크

### 도메인 (Porkbun)
- `mentor.sean2022.one` → A 레코드 `122.46.32.43` (서버 PC의 공인 IP)
- **공인 IP가 바뀌면** Porkbun에서 `mentor`, `forest` 등 A 레코드를 새 IP로 바꿔야 합니다. (포레스트클럽 `.env`의 Porkbun API 키로 갱신 가능)

### 인증서 (HTTPS)
- 포레스트클럽과 같은 와일드카드 인증서(`*.sean2022.one`, Let's Encrypt)를 공유합니다. 파일: `D:\github\포레스트클럽\certs\sean2022.one-cert.pem`, `...-key.pem`
- **만료일: 2026-10-26.** 인증서를 갱신하면 파일이 바뀌므로 **mentor 서버를 재시작**해야 새 인증서를 읽습니다. (만료되면 브라우저에 경고가 뜨고 통화도 막힙니다.)

### 외부에서 접속되게 하려면 (한 번만)
1. **공유기 포트포워딩**: 외부 TCP `3004` → 서버 PC 내부 IP(예: 192.168.1.201) `3004`
2. **Windows 방화벽** (관리자 PowerShell):
   ```powershell
   New-NetFirewallRule -DisplayName "mentor HTTPS 3004" -Direction Inbound -Protocol TCP -LocalPort 3004 -Action Allow
   ```
3. 서버 PC의 내부 IP가 바뀌지 않도록 공유기에서 **고정 IP(DHCP 예약)** 설정
4. 다른 네트워크(휴대폰 LTE 등)에서 `https://mentor.sean2022.one:3004` 접속 확인

## 7. 자주 생기는 문제

| 증상 | 확인/조치 |
|---|---|
| 접속이 안 됨 | 서버 실행 여부(4-1) → 포트포워딩·방화벽(6장) → DNS(공인 IP 변경 여부) |
| 브라우저 인증서 경고 | 인증서 만료/갱신 후 미재시작. 재시작하고, 그래도 안 되면 인증서 파일 경로 확인 |
| "통화 기능이 아직 설정되지 않았어요" | `DAILY_API_KEY` 없음 → 설정 후 재시작 |
| 통화는 되는데 상대가 안 들어옴 | 상대 브라우저의 카메라·마이크 권한, https 접속 여부, Daily 무료 사용량 초과 여부 |
| 충전 신청 버튼이 안 눌림 | `BANK_INFO` 미설정 |
| 회원이 로그인 못 한다고 함 | 정지 여부(회원 탭), 비밀번호 초기화 필요 여부 |
| 서버 로그에 `database is locked` | 빌드 중이거나 다른 프로세스가 DB를 사용 중. 서버 중복 실행 여부 확인 |
| 서버가 이전 기능으로 동작 | 빌드 없이 재시작한 경우. `npm run build` 후 재시작 |
| 포트 3004가 이미 사용 중 | 4-1의 중지 명령으로 기존 서버 종료 후 재시작 |
