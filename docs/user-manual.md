# 미용 SOS 사용자 매뉴얼

미용 시술·매장 운영 중 막힌 문제를 올리고, 검증된 현직 전문가에게 답을 받는 서비스입니다.
접속 주소: **https://mentor.sean2022.one:3004** (휴대폰·PC 브라우저 모두 사용 가능)

---

## 1. 이렇게 이용해요

| 하고 싶은 일 | 방법 | 비용 |
|---|---|---|
| 궁금한 걸 올리고 여러 사람 답변 받기 | 질문하기 → 답변 확인 → 채택 | 무료 |
| 전문가와 1:1로 바로 해결하기 | 질문 상세 → 1:1 상담 신청 (채팅·보이스톡·페이스톡) | 코인 (아래 요금표) |
| 내 경험으로 도움 주고 수익 얻기 | 전문가 신청 → 승인 → 상담 참여 | 무료 (수익 발생) |

> **코인이란?** 서비스 안에서 쓰는 결제 수단입니다. **1코인 = 1원**이에요.

---

## 2. 시작하기

### 회원가입 / 로그인
1. 화면 오른쪽 위 **로그인** → **처음이신가요? 회원가입**
2. 아이디(영문 소문자·숫자·`_` 4~20자), 이름(닉네임), **직급(원장님·디자이너·인턴 중 선택)**을 입력
3. 휴대폰 번호를 입력하고 **인증번호 받기** → 받은 인증번호를 입력하고 **확인** (같은 번호로는 한 계정만 가입할 수 있어요, 중복가입 방지)
4. 비밀번호(8자 이상)를 입력하고 **가입하기**
5. 가입하면 바로 로그인됩니다. 이후에는 아이디·비밀번호로 로그인하세요.

로그인하면 위쪽에 🔔 알림, 보유 코인, **질문하기** 버튼과 메뉴(내 정보 · 전문가 신청 · 구인구직 · 직급 게시판 · 고객센터 · 로그아웃)가 보입니다.

### 직급 게시판
가입할 때 고른 직급(원장님/디자이너/인턴)에 맞는 게시판이 메뉴에 하나 생깁니다. **같은 직급 회원끼리만** 보고 쓸 수 있어요 (원장님은 디자이너 게시판을, 인턴은 원장님 게시판을 볼 수 없어요).

### 구인구직
**구인구직** 메뉴에서 **채용(구인)**과 **구직** 중 하나를 고르고 → 도시 → 지역(구/시/군)까지 클릭해서 들어가면 그 지역 글 목록이 보여요. 로그인하면 그 지역에 글을 쓸 수 있습니다.

### 비밀번호 바꾸기 / 잊었을 때
- 바꾸기: 위쪽 **내 이름 → 내 정보 → 비밀번호 변경** (현재 비밀번호 필요). 바꾸면 다른 기기의 로그인은 해제돼요.
- 잊었을 때: **고객센터**로 문의하면 본인 확인 후 관리자가 **임시 비밀번호**를 발급해 드려요. 받은 즉시 내 정보에서 새 비밀번호로 바꿔주세요.

## 3. 질문하고 답변 받기 (무료)

### 질문 올리기
1. **질문하기** 선택
2. 카테고리(펌·염색·탈색·커트·클리닉·매장운영), 제목, 상황을 입력
3. 모질·손상 이력, 약제·시간·온도를 적으면 답변이 정확해져요 (선택)
4. 사진을 최대 **3장(장당 5MB, JPG·PNG·WEBP·GIF)** 첨부할 수 있어요 (선택)
5. **질문 등록**

> ⚠️ **사진은 질문과 함께 누구에게나 공개됩니다.** 고객의 얼굴·이름·연락처가 보이면 가리거나 잘라서 올려주세요. 질문 본문에도 개인정보를 적지 마세요.

### 답변 확인 / 채택
- 질문 목록(홈)에서 카테고리로 골라볼 수 있어요. 누구나 무료 답변을 남길 수 있고, **검증 전문가**가 쓴 답변에는 배지가 붙습니다.
- 내 질문의 답변 중 도움이 된 것을 **채택하기**를 누르면 질문이 **해결됨**으로 바뀝니다. 질문을 올린 본인만 채택할 수 있어요.
- 새 답변이 달리면 🔔 알림이 와요.

## 4. 코인 충전하기

**코인** 버튼(또는 상단 코인 표시) → 코인 화면

### 무통장입금
1. 충전할 금액 선택 (최소 1,000원)
2. 화면에 표시된 **입금 계좌**로 입금
3. **입금자명**을 입력하고 **충전 신청 (무통장입금)**
4. 관리자가 입금을 확인해 승인하면 코인이 충전되고 알림이 옵니다. (상태: 입금 확인 대기 → 충전 완료)

> 입금자명과 실제 입금자명이 다르면 확인이 늦어져요. 반려되면 알림에 사유가 표시됩니다.

### 카드 결제
카드 결제가 열려 있으면 **카드로 바로 충전** 버튼이 보입니다. 결제가 끝나면 즉시 충전됩니다.

### 내 코인 내역
코인 화면 아래에서 **충전 내역**과 **사용 내역**(상담 시작비, 메시지, 통화, 환불 등)을 모두 볼 수 있어요.

## 5. 전문가와 1:1 상담하기

### 요금표

| 항목 | 요금 |
|---|---|
| **상담 시작비** | **50,000코인** (상담 신청 시 1회) |
| 쪽지(채팅) | **글자당 10코인**, 최소 500코인 · 한 메시지 **200자 이내** (최대 2,000코인) |
| 사진·파일 첨부 | 메시지 요금에 **+500코인** |
| 보이스톡 | **초당 10코인** (분당 600코인) |
| 페이스톡 | **초당 100코인** (분당 6,000코인) |

- 요금은 **상담을 신청한 질문자에게만** 부과됩니다. **전문가는 무료**로 답변·통화해요.
- 예) 5자 메시지 = 500코인(최소요금), 120자 = 1,200코인, 200자 = 2,000코인.
- 통화 **요청**은 무료이고, **통화 중인 시간**에만 초당 요금이 붙어요.

### 상담 시작하기 (질문자)
1. 내 질문 상세 → **전문가와 1:1 상담 신청**
2. 요금 안내를 확인하고 **50,000코인 결제하고 상담 시작** (코인이 부족하면 먼저 충전)
3. 채팅방이 열리면 궁금한 점을 남기세요. 전문가가 참여하면 알림이 옵니다.

> **전문가가 참여하기 전에는 언제든 전액 환불로 취소**할 수 있어요 (채팅방 위쪽 **취소·환불**). 시작비와 그동안 쓴 메시지 요금이 모두 돌아옵니다. 전문가가 참여한 뒤에는 취소할 수 없고, 문제가 있으면 고객센터에 **환불 요청**을 접수하세요.

### 채팅
- 아래 입력창에 메시지를 쓰고 **전송**. 입력창 아래에 글자 수와 **이 메시지의 요금**이 미리 표시됩니다.
- 📎 버튼으로 사진·파일을 보낼 수 있어요 (15MB 이하, 이미지·PDF·문서·zip 등).
- 새 메시지는 약 3초마다 자동으로 나타나요.
- 상담 참여자(질문자와 참여한 전문가) 외에는 대화를 볼 수 없어요.

### 보이스톡 · 페이스톡
1. 입력창 왼쪽 📞(보이스톡) 또는 📹(페이스톡) 누르기
2. 통화방이 만들어지고 화면이 통화 창으로 바뀝니다. 상대방은 채팅에 뜬 **통화 참여** 버튼으로 들어와요.
3. 통화 중 화면 아래에서 **통화 시간·사용 코인·잔액**을 볼 수 있어요.
4. **종료** 버튼을 누르면 통화가 끝나고, **상대방 화면도 함께 종료**됩니다.

- 통화를 시작·참여하려면 잔액이 **3,000코인을 넘어야** 해요.
- 통화 중 잔액이 **1,500코인 이하**가 되면 자동으로 종료돼요.
- 휴대폰에서 통화하려면 브라우저의 **카메라·마이크 권한**을 허용해 주세요. (https 주소로 접속해야 합니다.)

### 상담 마치기와 후기
- 채팅방 위쪽 **상담 종료**를 누르면 종료돼요. 종료 후에는 메시지·통화를 할 수 없습니다.
- 질문자는 종료 후 **별점(1~5점)과 후기**를 남길 수 있어요 (상담당 1회). 후기는 전문가 프로필에 공개됩니다.

## 6. 전문가로 활동하기

### 전문가 신청
1. 위쪽 메뉴 **전문가 신청** → 경력·자격(미용사 면허 등)·전문 분야를 **20자 이상** 작성 → 신청
2. 관리자가 검토해 **승인/반려**하면 알림이 옵니다. (반려되면 보완해 다시 신청)
3. 승인되면 메뉴가 **전문가 센터**로 바뀌고, 답변에 **검증 전문가** 배지가 붙어요.

### 상담 참여
- 질문 상세에서 상담이 열린 질문을 열면 **상담 참여하기 (전문가)** 버튼이 보여요. 한 상담에는 전문가 1명만 참여할 수 있습니다.
- 채팅방에서 첫 메시지를 보내도 참여로 처리됩니다.
- 전문가는 메시지·통화가 **무료**입니다.

### 수익과 출금
- 질문자가 낸 금액(시작비·메시지·통화)의 **70%**가 내 수익으로 쌓여요. 상담에 참여하는 순간, 그때까지 질문자가 쓴 금액도 함께 정산됩니다.
- **전문가 센터**에서 출금 가능 수익, 수익 내역, 출금 내역을 볼 수 있어요.
- **출금 신청**: 금액(**최소 10,000코인**)과 은행·계좌번호·예금주를 입력 → 관리자가 확인 후 이체하면 알림이 옵니다. 반려되면 수익으로 되돌아와요.
- 내 공개 프로필(평점·후기·완료한 상담 수)은 **내 정보 → 내 공개 프로필 보기**에서 볼 수 있어요.

## 7. 알림

위쪽 🔔에 안 읽은 알림 개수가 표시됩니다. 눌러서 목록을 보고, 알림을 누르면 해당 화면으로 이동해요. **모두 읽음**으로 한 번에 정리할 수 있어요.

알림이 오는 경우: 새 메시지 · 전문가 상담 참여 · 내 질문에 답변 · 충전 승인/반려 · 전문가 승인/반려 · 출금 지급/반려 · 문의 처리 · 후기 등록

## 8. 고객센터

메뉴 **고객센터**에서 접수하면 처리 결과가 알림과 **내 문의** 목록에 나타납니다.

| 종류 | 이럴 때 |
|---|---|
| 불만·클레임 | 서비스 이용 중 불편·문제 |
| 환불 요청 | 전문가 참여 후 상담에 문제가 있었을 때 (사유를 자세히) |
| 회원 신고 | 욕설·부적절한 행동 등. **신고할 회원의 아이디**를 입력 |
| 기타 | 비밀번호 초기화 등 |

> 같은 회원에 대한 신고가 **5건** 쌓이면 해당 계정은 자동으로 이용이 정지됩니다. 허위 신고는 하지 말아주세요.

## 9. 자주 묻는 질문

**Q. 코인을 충전했는데 반영이 안 돼요.**
무통장입금은 관리자 확인 후 반영돼요. 충전 내역에서 상태를 확인하고, 오래 걸리면 고객센터로 문의하세요.

**Q. 메시지가 전송되지 않아요.**
① 200자를 넘었는지, ② 코인이 충분한지(입력창 아래 요금 확인), ③ 상담이 종료되지 않았는지 확인하세요.

**Q. "통화 기능이 아직 설정되지 않았어요"가 떠요.**
서비스 쪽 설정 문제입니다. 관리자에게 알려주세요.

**Q. "코인이 3,000개 이하면 통화를 시작할 수 없어요"가 떠요.**
통화는 잔액이 3,000코인을 넘어야 시작할 수 있어요. 충전 후 다시 시도하세요.

**Q. 전문가가 오래 참여하지 않아요.**
참여 전에는 전액 환불로 취소할 수 있어요. 취소 후 다시 신청하거나, 무료 답변을 기다려 보세요.

**Q. 계정이 정지됐다고 나와요.**
신고 누적 또는 관리자 조치로 정지된 계정이에요. 고객센터 안내에 따라 문의해 주세요.

**Q. 사진을 잘못 올렸어요.**
아직 사진 삭제 기능이 없어요. 고객센터로 요청해 주세요.

- 비밀번호를 다른 사람과 공유하지 마세요. 공용 기기에서는 사용 후 **로그아웃**하세요.
- 서비스 밖에서 금전 거래를 유도하는 행위는 신고 대상입니다.
